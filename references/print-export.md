# Деталь для 3D-печати: проектирование, проверка, экспорт

Речь о FDM-печати (пластиковая нить, сопло 0.4 мм) — самый частый случай. Цифры ниже —
ориентиры, а не законы; если у пользователя другое сопло или материал, скорректируй.

## Проектирование под печать

| Что | Ориентир | Почему |
|---|---|---|
| Толщина стенки | ≥ 0.8 мм, лучше 1.2–3 мм | стенка печатается периметрами по ~0.4 мм; тоньше двух — хрупко |
| Нависания | до ~45° от вертикали без поддержек | круче — нужны поддержки или фаска вместо скругления |
| Мосты | горизонтальные пролёты до ~30–40 мм печатаются без поддержек | принтер «перекидывает» нить между опорами |
| Отверстия | печатаются на 0.1–0.2 мм уже | заложи запас или предупреди, что их можно прогнать сверлом |
| Зазор посадки | 0.2–0.3 мм на сторону (свободная), ~0.1 мм (плотная) | точность FDM ±0.1–0.2 мм |
| Нижние кромки | фаска 0.3–0.5 мм вместо скругления | скругление снизу — нависание; фаска гасит «слоновью ногу» первого слоя |
| Скругления | не меньше ~0.3–0.5 мм | меньше принтер не воспроизведёт |
| Текст, рельеф | высота букв ≥ 5 мм, глубина ≥ 0.6 мм | мелкое сливается |

- **Ориентация.** Большая плоская грань — на стол. Прочность поперёк слоёв ниже: нагрузку
  лучше направлять вдоль слоёв. Для корпусов обычно «открытым низом на стол» — поддержки почти
  не нужны.
- **Материал.** PLA — просто и точно, но боится жары и солнца. PETG — прочнее, терпит тепло.
  ASA — для улицы (не боится ультрафиолета), нужен закрытый принтер. TPU — гибкий.
- **Размер стола.** Сверь габарит с принтером; не влезает — предложи разрезать с замками.

## Проверка модели перед экспортом

1. Отчёт о состоянии (сниппет 2): одно тело `solid`, `shells 1`, история без ошибок.
2. Микрограни (сниппет 7): грани шириной < 0.1 мм — признак неточной стыковки поверхностей.
3. Тонкие места: сними сечения модели (сниппет 8) через подозрительные зоны и проверь толщину
   стенок по точкам сечения; для наглядности — screenshot с нужной стороны.

## Экспорт

Сниппет 11 (`snippets.md`): STL для слайсера и STEP — точная модель для любой CAD-программы.
- `MeshRefinementHigh` — для печати; `Low`/`Medium` — для лёгких файлов (например, видео).
- Двоичный STL (`isBinaryFormat = True`) — меньше и быстрее.
- Папка — проекта пользователя (например, `C:\Projects\<имя>\`; если её нет — создай), не служебная папка Claude.

## Проверка STL (вне Fusion)

`<scripts>` — папка программ скилла (см. SKILL.md):
```
py <scripts>\check_stl.py C:\Projects\<имя>\part.stl
```
Ожидай: `открытых или разветвлённых (non-manifold) рёбер: 0`, габарит в мм совпадает с
моделью, объём разумный (в мм³; /1000 = см³). Масса PLA/PETG ≈ объём (см³) × 1.24–1.27 г при
100 % заполнении — реально меньше, зависит от заполнения.

## Что сказать пользователю

- Где лежат файлы и что это: `.stl` — для слайсера, `.step` — для доработки.
- Как импортировать в его слайсер (Bambu Studio / PrusaSlicer / Cura: File → Import), как
  положить деталь, нужны ли поддержки.
- Настройки, которые стоит поменять: число периметров для толстых стенок (стенка 2.9 мм при
  линии 0.42 мм ≈ 7 периметров, чтобы была сплошной), материал.
- Предупреждения: маленькие отверстия уже, тонкая юбка на столе и т.п.
