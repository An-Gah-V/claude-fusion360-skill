# Координаты, единицы, оси эскизов

## Единицы

| Что | Во Fusion API | Как перевести |
|---|---|---|
| Длина | сантиметры | мм × 0.1 → см; см × 10 → мм |
| Угол | радианы | `math.radians(град)` |
| Площадь, объём | см², см³ | мм² = см² × 100; мм³ = см³ × 1000 |
| Параметр пользователя `.value` | см (для длины) | `.expression` — строка как у пользователя (`'60 mm'`) |

`design.unitsManager.defaultLengthUnits` — единицы, которые видит пользователь (обычно `'mm'`).
Для надёжности передавай размеры строкой: `ValueInput.createByString('12.5 mm')`.

## Мировые оси

Правая система: X вправо, Y от зрителя, Z вверх. В наших проектах «верх детали» — **+Z**
(камера для кадров: `upVector = (0, 0, 1)`). Координаты в API не зависят от настройки
«Y up / Z up» в интерфейсе, но от неё зависит, что пользователь (и `screenshot` коннектора)
считает видом «сверху» и «спереди». Поэтому ракурс скриншота сверяй по картинке, а в
разговоре с пользователем называй направления осями (+Z, −Y), а не только словами.

## Эскизы на базовых плоскостях (проверено вживую)

Тест: прямоугольник в эскизе x = 1…2, y = 3…4 (см), выдавливание +0.5 см:

| Плоскость | Ось X эскиза → мир | Ось Y эскиза → мир | Выдавливание «+» идёт в | Получилось тело (мир, см) |
|---|---|---|---|---|
| `xYConstructionPlane` | +X | +Y | +Z | (1, 3, 0) – (2, 4, 0.5) |
| `xZConstructionPlane` | +X | **−Z** | +Y | (1, 0, −4) – (2, 0.5, −3) |
| `yZConstructionPlane` | **−Z** | +Y | +X | (0, 3, −2) – (0.5, 4, −1) |

Вывод: на XZ, чтобы получить мировую высоту Z = 3…4, в эскизе нужен y = −4…−3. На YZ высота Z
берётся из **x** эскиза со знаком минус.

Не держи эту таблицу в голове — спрашивай у эскиза:
```python
p_sk = sk.modelToSketchSpace(adsk.core.Point3D.create(x_cm, y_cm, z_cm))   # мир -> эскиз
p_w  = sk.sketchToModelSpace(adsk.core.Point3D.create(u, v, 0))            # эскиз -> мир
print(sk.xDirection.asArray(), sk.yDirection.asArray())                     # куда смотрят оси эскиза
```
Для эскиза на **грани** детали это единственный надёжный способ: оси там выбирает Fusion.

## Плоскость со смещением

```python
pin = comp.constructionPlanes.createInput()
pin.setByOffset(comp.xYConstructionPlane, adsk.core.ValueInput.createByString('ledge_z'))  # можно выражение
plane = comp.constructionPlanes.add(pin); plane.name = 'Ledge plane'
```
Смещение от XY — это высота по Z.

## Плоскость как «n·p = d»

В реверс-инжиниринге грань удобно хранить уравнением: единичная нормаль `n` и расстояние `d`
(мм): точки грани удовлетворяют `n·p = d`, а «снаружи» — `n·p > d`. Так их выдаёт
`scan_tools.py planes`, и так их принимает сниппет «Брусок-срез».

## Матрицы (Matrix3D)

- `m.setWithArray(CELLS)` — 16 чисел **по строкам**: `[r00, r01, r02, tx, r10, r11, r12, ty, r20, r21, r22, tz, 0, 0, 0, 1]`,
  сдвиг `tx, ty, tz` — в **см**. `scan_tools.py matrix` печатает именно такой `CELLS`.
- Точка: `p' = R·p + t`. Нормали поворачивай только `R` (без сдвига).
- Поворот вокруг оси через точку: `m.setToRotation(угол_рад, Vector3D_оси, Point3D_центра)`.
- `m.invert()` меняет матрицу на месте; `m.setWithCoordinateSystem(origin, xAxis, yAxis, zAxis)`
  строит матрицу «локальные → мировые».

## Проверка «куда легло»

После каждой операции печатай габарит в мм и сравнивай с ожиданием:
```python
bb = body.boundingBox
print('bbox mm', [round(v * 10, 2) for v in (bb.minPoint.x, bb.minPoint.y, bb.minPoint.z,
                                                bb.maxPoint.x, bb.maxPoint.y, bb.maxPoint.z)])
```
Если тело ушло «вниз» или «назад» — почти всегда это знак оси эскиза или направление
выдавливания.
